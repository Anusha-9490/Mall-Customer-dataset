# Mall Customer Segmentation using K-Means Clustering

## Project Overview

This project uses **Machine Learning** to segment mall customers into different groups based on their **Annual Income** and **Spending Score**.

The **K-Means Clustering** algorithm is used to identify customer groups with similar purchasing behavior.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab

## Dataset

The project uses the **Mall Customer Segmentation Dataset**.

The main features used for clustering are:

* Annual Income
* Spending Score

## Algorithm

**K-Means Clustering**

K-Means groups customers into clusters based on the similarity between their feature values.

## Project Steps

1. Import the required libraries.
2. Load the customer dataset.
3. Explore and understand the dataset.
4. Select the required features.
5. Determine the optimal number of clusters.
6. Apply K-Means Clustering.
7. Visualize the customer clusters.
8. Analyze the customer segments.

## Results

The model divides customers into different groups based on their income and spending behavior. These customer segments can help businesses understand their customers and improve marketing strategies.

## How to Run

1. Open the project in **Google Colab**.
2. Upload the dataset.
3. Run the Python code cells step by step.
4. View the clustering results and visualizations.
